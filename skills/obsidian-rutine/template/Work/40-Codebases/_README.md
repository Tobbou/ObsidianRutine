# 40 - Codebases

Notes about specific codebases: architecture, decisions and the why, runbooks, post-mortems, hard-won fixes. One subfolder per codebase.

''Codebase'' covers anything you maintain code-like artefacts in - git repos, scripts, low-code apps, spreadsheets with macros. Set `platform:` in the frontmatter so the folder stays filterable.

Start from the `codebase-note.md` template.
