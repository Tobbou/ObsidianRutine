# 00 - Inbox

Fast capture. Drop anything here when you don't know where it belongs yet.

**When to use:** quick thought, link to read later, half-formed idea, anything you don't want to lose but don't have time to file.

**Rule:** triage regularly (weekly is enough). Move notes out to their real home, or delete. If the inbox grows past ~20 items, it's no longer working as an inbox.

**Don't:** link to inbox notes from elsewhere - they're meant to move.
